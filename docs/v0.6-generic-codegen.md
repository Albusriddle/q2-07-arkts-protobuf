# V0.6：通用 message / nested / oneof codegen

日期：2026-10-30 ｜ 分支：`feature/v0.6-generic-codegen` ｜ 基线：`main` `cfc9e18`（V0.5）

## 0. 结论

V0.6 去掉了 generator 对 `Profile/User/UserBatch` struct/parser 的硬编码：
POD、decoder、ArkTS interface 现在按 schema 的 message 图生成，并保留当前
`User`/`UserBatch`/`object_model`/tape 的 API 与行为。

**仍是 schema 子集生成器**：支持 scalar `string/int32/int64`、repeated、optional、
oneof、nested message；map 仍限定为单一 `key/value` shape。

## 1. 变更

| 文件 | 变更 |
|---|---|
| `scripts/gen_fields.py` | `generate_pod` / `generate_decoder` / `generate_dts` 改为 message-graph 驱动 |
| `src/host/decoder/decode_user.cpp` | 改为调用 `parse_user`（generated name） |
| `src/host/decoder/generated/*` | 重新生成 |
| `scripts/test_gen_fields.py` | 新增 synthetic nested/optional/oneof schema 生成测试 |
| `docs/v0.6-generic-codegen.md` | 本文 |

生成顺序由 message 依赖图拓扑排序；`UserBatch.users` 保留 batch-specific
`max_batch_users`/`max_objects` 规则；重复 message 字段先 `enter_length` 再
`emplace_back`，避免错误路径留下部分对象。

## 3. 限制

1. **map shape**：多个不同 map key/value 类型会 fail-closed；当前是 `string/int32`。
2. **scalar 子集**：`bytes/fixed/enum` 等仍会被 `validate_decoder_support` 拒绝。
3. **NAPI/设备**：fake NAPI 仍是 host-only，真实 ArkCompiler/设备未验证。
4. **object_model/tape 仍是 User 专用**；其他 message 可生成 POD/decoder，但通用 materializer 未做。
