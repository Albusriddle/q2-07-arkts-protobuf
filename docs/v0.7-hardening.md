# V0.7：map/CI/文档审阅修复

日期：2026-10-30 ｜ 分支：`feature/v0.7-map-hardening` ｜ 基线：`main` `8b0b637`（V0.6）

## 0. 结论

V0.7 修复了全仓审阅中的代码/文档问题，重点是：

- per-field map entry，多 map shape 不再共用 `MapEntry`；
- string map value 默认值修正（不再生成 `std::string value = 0`）；
- DTS map key 类型按 key 生成；
- 保留 `Profile` 未知字段不计数行为；
- `napi_shim_test` 显式 `<iterator>`；
- CI 统一走 `scripts/ci_host.sh`，增加 ASan job；
- 文档/证据指针更新。

**仍未设备运行**；真实 NAPI/device/performance 仍为 block。

## 1. 修复项

| 项 | 修复 |
|---|---|
| map<string,string> 非法 POD | per-field entry + 类型正确默认值 |
| 多 map shape | 每个 map 字段独立 `<Message><Field>Entry` |
| DTS map key | `Record<string/int, ...>` 按 key 类型 |
| Profile unknown fields | 保持旧行为：不增加 `unknown_fields` |
| napi shim CI | 显式 `<iterator>` |
| CI | `ci_host.sh` 统一入口 + ASan/UBSan job |
| 文档 | `src/host/README`、`docs/v0.2`、`RISKS`、`docs/v0.6` 更新 |

`MapEntry` 仍作为当前 `User.scores` 的兼容 alias，object_model/tape 不需要改动。
