# V0.5：fake NAPI host runtime smoke tests

日期：2026-10-30 ｜ 分支：`feature/v0.5-napi-ci` ｜ 基线：`main` `65baad7`

## 0. 结论

V0.5 新增 **host-only fake NAPI**，直接执行 `app/entry/src/main/cpp/decode_napi.cpp`
的 `DecodeUser/DecodeMany`，验证对象构造、数组、错误输入和 handle scope 平衡。
这是 **fake NAPI**，不是 ArkCompiler/Node；`device_run=false`。

## 1. 实现

- `src/host/tests/napi_shim/napi/native_api.h`：最小 fake NAPI 头，仅覆盖 binding 使用的 API。
- `src/host/tests/napi_shim/fake_napi.cpp`：mock value/object/array/typedarray/scope/exception。
- `src/host/tests/napi_shim/napi_shim_test.cpp`：
  - `DecodeUser(c20_full)` 返回 object，id/name/tags/profile/scores 类型正确；
  - `DecodeMany(c20+empty)` 返回 `{users:[user, default]}`；
  - 空 batch `{users:[]}`；
  - 非 `Uint8Array` 抛错；
  - 截断 batch 抛错；
  - handle scope open/close 平衡。
- `scripts/build_host.sh` 新增 `napi-shim` step，编译并运行 `napi_shim_tests`。
- `.github/workflows/ci.yml` 在 Ubuntu 上跑 codegen、负例、sample 和 host 468 断言。

## 3. 限制

- fake NAPI 只验证 host 对象映射和 scope 计数，不验证 ArkCompiler 的句柄/异常/线程行为。
- 设备/真实 NAPI 仍是 P1 block。
- 没有新增业务功能；`decode_napi.cpp` 只做了编译期 fake header 替换。
